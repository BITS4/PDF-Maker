# Community conduct

PDF Maker welcomes focused, constructive participation.

## Expected behavior

- Discuss code and outcomes without personal attacks.
- Give specific, actionable review feedback.
- Respect different experience levels, identities, languages, and accessibility needs.
- Protect user privacy; never post confidential documents, credentials, or personal data.
- Disclose security problems privately through the process in `SECURITY.md`.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate disruption, publishing another person's private information,
or using project spaces for spam is not accepted.

## Enforcement

Report conduct concerns privately to the repository owner. Maintainers may edit or remove contributions and restrict
participation when necessary to protect contributors and users. Reports will be handled as confidentially as practical.
